# Employee Lifecycle Portal

Enterprise Human Resource Management System (HRMS)

---

# Overview

Employee Lifecycle Portal is a production-ready enterprise backend built with ASP.NET Core following Clean Architecture and CQRS principles.

The goal is to build an HRMS comparable to enterprise products used by large organizations while demonstrating modern backend engineering practices.
